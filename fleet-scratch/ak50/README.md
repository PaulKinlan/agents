# ak50 scratch: the mid-migration tooling for the suite world-shape migration

PARKING PLACE. **This branch must not be landed.** It publishes the scripts and the evidence that took the whole pass to
produce, so that a VM reset cannot take them; it is not a delivery and it is not a candidate for the merge queue.

`build.sh` builds both trees from the pristine copies and GUARDs the (B) field rule. `restore-M.sh` does three checked
steps (base, shape, declarations) and lands on the state measured as ak50-T. `shape.sh` holds the helper block that was
proved in isolation before it was installed: declare two lanes, run, ZERO files, re-declare, exactly one.
The parked `.suite-*.out` files are the ak50-T run - red 362/6 with the control being exactly the six discriminators, no
case failing on both sides - and `ak50-S-tree-fingerprint.txt` is how that reading is bound to the tree that produced it.
