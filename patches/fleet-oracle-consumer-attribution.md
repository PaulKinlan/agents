**Changes:**
1. Keep import-based attribution primary. Recognize Python package importers only when the package initializer itself imports the changed child, using the Python AST to distinguish `import lib.sinks` or `from lib import sinks` from a sibling-module import. Preserve direct `has_import_reference()` detection for the true GitHub importer.
2. Replace the unconstrained `run|fork|call|...` source-text grep with narrowly recognized process APIs and **quoted literal paths/module names** in their argument list. A bare executable word, a flag, arbitrary `process_run`, or a `_run` definition is not evidence. The agents-0xm2 section-8 controls still recognize explicit `python3 -m lib.sandbox` and `node scripts/api` executions while excluding `bwrap --sandbox`.
3. Treat `test_<stem>` and `<stem>_test` as explicit names even when source/test extensions differ, comparing `-` and `_` as equivalent separators, in both candidate discovery and naming fallback. Bare-stem and `.test`/`.spec` cross-language matches retain the older extension gate. A wrong suite still reports the changed tool as unmapped and names the unrun cross-extension candidate.
4. Add section 9 of `tests/check-coverage.test.sh`: four phantom-candidate controls, real GitHub importer omitted/covered controls, the package/sibling-import pair, and the shell/Python affixed-name covered/wrong-suite pair. Do **not** alter `UNKNOWN`, `PARTIAL`, the fail-loud no-candidate/no-suite fallback, `bin/fleet-check`, or their pinned contracts. A general UNKNOWN-for-unattributable-source policy conflicts with `tests/fleet-gate-check.test.sh` 14j/m/n/o/p and `tests/project-template.test.sh` D17 and is deliberately separately blocked for hub contract work.

**Trade-offs / honest limits:** a process invocation that constructs its executable path dynamically without a quoted literal is not inferred by the CLI rule; an explicit affixed test name may still find such a test, or the existing no-candidate fallback remains fail-loud. Package importers are only inferred when the initializer imports the child; this does not chase arbitrary dynamic registries. Naming correspondence is evidence of selection, not proof that a test asserts runtime behaviour: section 9 checks omitted-true and wrong-suite cases, while agents-5jjf independently pins the actual GitHub promote-lock consumer.
