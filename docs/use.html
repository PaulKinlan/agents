Use the factory

Run one station or an ordered Line. Read the result and routing policy before automating.

On this page

  • One station
  • A Line
  • Sinks & visibility
  • CLI reference

Run one station

./factory list
./factory run secret-scan --target . --sink file
./factory run docs-drift --target . --engine pi --sink file

--target accepts a registered name or local directory. The engine is selected automatically unless overridden. Only choose Beads where the target has a configured destination.

Run a Line

./factory line project-audit --target . --sink file
./factory line web-excellence --target . --sink file

Stations run in declared order. Read the Andon policies before relying on a Line as a gate; an environment failure and a finding are different outcomes.

Sinks & visibility

File

Default local fallback. Review the local delta outside the published Pages site.

Beads

On a configured target, medium-and-above triaged findings file automatically and dedupe by fingerprint. Missing visibility withholds high/critical from the synced tracker.

No public findings issue sink.

github-issues is rejected as a findings sink. The issue-triage station handles public input; promote links an approved public issue to a Beads item. Do not publish raw run evidence.

For ad-hoc paths, --visibility public|private declares routing policy; a registered target’s own declaration wins.

CLI at a glance

Flags below are a snapshot; the next generator must fill this block from argparse and nested command help. Run ./factory <command> --help for authoritative options.

integrate

Print recipes for agents and CI.

./factory integrate [--agent] [--section all|github-actions|pre-commit|target|skills|agents]

list

Show available stations.

./factory list [-h]

promote

Create one linked bead from an approved public issue on a configured target.

./factory promote --target NAME --issue URL

run

Run a station.

./factory run AGENT --target TARGET [--engine auto|pi|claude|antigravity|deepseek] [--model MODEL] [--sink file|beads] [--visibility public|private]

line

Execute an ordered Line.

./factory line LINE --target TARGET [--engine auto|pi|claude|antigravity|deepseek] [--model MODEL] [--sink file|beads] [--visibility public|private]

hillclimb

Iterate toward a measured performance goal.

./factory hillclimb --target TARGET [--metric METRIC] [--goal GOAL] [--iterations N] [--apply] [--engine ENGINE] [--sink file|beads] [--visibility public|private]

hook

Install a deterministic pre-commit hook.

./factory hook install [--target TARGET] [--all]

skills

Install interactive skills links.

./factory skills install

schedule

Manage launchd/systemd runs.

./factory schedule list|generate|install|uninstall|trigger [--target TARGET] [--agent AGENT] [--all] [--platform auto|launchd|systemd|darwin|linux|all]
