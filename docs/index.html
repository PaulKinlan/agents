Software Factory

A local-first, schedulable fleet for software-development work. Inspect a station, compose a Line, and route findings without surrendering review.

Run focused agents on demand or in CI. Deterministic tools find candidates; isolated AI sessions judge them; the factory routes verified results to the target’s configured destination.

The run, at a glance

  1. Pre-pass Enumerate candidate signals with tools.
  2. Engine Triage in a bounded session.
  3. Sink Dedupe and route the result.

Keep humans in control

Track findings in local files or the configured Beads tracker. Proposals are not automatic default-branch changes.

One pipeline, clear boundaries

  1. Pre-pass Deterministic discovery supplies bounded candidate evidence.
  2. Engine An agent skill and adapter triage candidates; separate verification can disprove discoveries.
  3. Sink Fingerprint and dedupe findings, then use file or configured Beads.
Andon is a stop signal, not a success metric.

Lines record a critical defect or environment failure honestly. An incomplete station never becomes a clean result.

Start with one station

Python 3.9+ and an authenticated supported AI CLI are needed for model work. Start with a local file sink; add tracker routing intentionally.

git clone https://github.com/PaulKinlan/agents.git
cd agents
./install.sh
./factory list
./factory run secret-scan --target . --sink file
